# جسور التسامح — مشروع تفاعلي

واجهة عربية متجاوبة لمبادرة «أثر التسامح»، تجمع الطلاب وأولياء الأمور والمعلمين عبر:
- نموذج مشاركة حسب الفئة مع أسئلة مخصصة.
- شجرة تفاعلية تنمو بأوراق المشاركات المعتمدة.
- جدار رسائل يعرض الرسائل المعتمدة فقط.
- عدادات إجمالية وعدّادات حسب الفئة.
- وضع محلي للمعاينة، وربط اختياري بـ Supabase لتجميع المشاركات من أجهزة متعددة.

## تشغيل المعاينة
افتح `index.html` في متصفح حديث. وضع المعاينة المحلي لا يرسل البيانات إلى الإنترنت ولا يشاركها بين الأجهزة.

## تفعيل المشاركة الحقيقية بين الجميع
1. أنشئ مشروع Supabase.
2. افتح SQL Editor وشغّل محتوى `supabase_schema.sql`.
3. من Project Settings > API انسخ Project URL و anon/public key.
4. تم إدخال Project URL وPublishable Key العام في `app.js` لهذه النسخة.
5. ارفع محتويات مجلد `athar_al_tasamuh` إلى استضافة Static مثل Netlify أو Vercel أو GitHub Pages.

**مهم:** لا تضع `service_role` key في `app.js` أو أي ملف يصل للمتصفح. سياسات RLS في SQL تسمح بإرسال المشاركات بحالة `pending` وقراءة `approved` فقط.

## مراجعة المشاركات
من Supabase Dashboard > Table Editor > submissions:
- راجع نص المشاركة.
- غيّر `status` إلى `approved` لنشرها.
- أو غيّره إلى `rejected` لرفضها.

لا توجد واجهة إدارة عامة عمدًا؛ حتى لا يستطيع أي زائر اعتماد مشاركاته بنفسه. يمكن لاحقًا بناء لوحة مشرف محمية بتسجيل دخول وصلاحيات منفصلة.

## الخصوصية والسلامة
- لا تطلب المنصة اسم الطالب أو رقم هاتفه أو صفه أو بريده.
- وجّه المشاركين لعدم إدخال أسماء أشخاص أو تفاصيل حساسة.
- يجب أن تتولى المدرسة الإشراف على المبادرة ومراجعة المشاركات قبل النشر، مع الالتزام بسياسات المدرسة وموافقة الجهة المسؤولة وأولياء الأمور عند الحاجة.
- أضف سياسة خصوصية وبيانات تواصل المدرسة قبل الإطلاق الرسمي.
- لا تستخدم بيانات تجريبية حقيقية للطلاب.

## الملفات
- `index.html`: بنية الصفحات.
- `styles.css`: الهوية البصرية والحركة والتجاوب.
- `app.js`: التفاعلات والربط الاختياري بقاعدة البيانات.
- `supabase_schema.sql`: الجداول وسياسات الوصول.


## حالة هذه النسخة
- تم إعداد `app.js` برابط مشروع Supabase والمفتاح العام الذي زودنا به المستخدم.
- لم يتم اختبار اتصال حي من بيئة إنشاء الملف؛ بعد النشر اختبر إرسال مشاركة تجريبية، ثم راجعها في جدول `submissions`.
- لا تشارك أي Secret Key. المفتاح الموجود في الواجهة هو Publishable Key المخصص للاستخدام العام مع سياسات RLS.
